# 2026-04-08 safe-nfc-analyzer

## 배경

저장소가 비어 있는 상태에서, 개인 소유 NFC 태그의 공개 메타데이터만 분석하는 안전한 안드로이드 앱이 필요했습니다.

## 문제 또는 목표

- 공개 메타데이터만 읽는 NFC 분석기 구현
- 법적 경고와 동의 절차 제공
- 로컬 기록 저장, 상세 조회, 텍스트 보고서 공유 지원
- 복제/덤프/인증 기능 배제

## 변경 내용

- Compose + MVVM + Hilt + Room 기반 안드로이드 앱 초기화
- `NfcA` 공개 메타데이터 읽기 흐름 구현
- Room DB 기록 저장 및 JSON 아카이브 파일 작성 구현
- 기록 목록 / 상세 화면 및 텍스트 보고서 공유 기능 추가
- 한국어 README, AGENTS, CI 워크플로우 추가

## 설계 이유

- NFC 접근을 `feature/nfc/`로 격리해 안전 경계를 명확히 했습니다.
- Room과 JSON 파일을 함께 사용해 앱 내부 조회와 외부 점검 가능성을 동시에 확보했습니다.
- 최초 실행 경고를 강제해 기능 사용 전 법적 안내를 분명히 했습니다.

## 영향 범위

- 새 안드로이드 프로젝트 전체
- GitHub Actions CI
- 한국어 개발 문서 및 사용자 문서

## 검증 방법

- `./gradlew assembleDebug`
- `./gradlew testDebugUnitTest`
- `./gradlew lintDebug`

## 남아 있는 한계

- 실제 NFC 스캔의 수동 검증에는 물리 기기가 필요합니다.
- JSON 파일 공유 UI는 아직 제공하지 않습니다.
- 메모(`label`) 편집 UI는 아직 없습니다.

## 후속 과제

- 기록 검색/필터링 추가
- JSON 파일 공유 UI 추가
- 계측 테스트 및 실제 기기 기반 수동 검증 보강
